Welcome to the quantum machine learning and data analysis learning path.

In this path you will learn how quantum computing can be combined with classical machine learning and data-analysis workflows. Lessons will explore topics such as quantum data encoding, quantum and hybrid models, integration with accelerated classical frameworks, and evaluation against classical baselines. The path will also emphasize practical questions about trainability, resource requirements, and when a quantum component is useful.

## Notebooks

The Jupyter notebooks in this folder are designed to run in an environment with CUDA-Q and Python. Some notebooks require a GPU; check the callout near the beginning of each notebook.
